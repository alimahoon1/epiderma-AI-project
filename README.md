EpiDerma: An acne detection app.
install the requirements.txt in the backend folder, that should install all the dependencies needed.
run the backend and the frontend.
attach the photo u want to check and then the app shoould display the lesions it detected.
the detected photo would include the type of lesion and the location including the confidence score.
on the sidebar it would also tell the severity of the acne the photo has.
the app uses machine learning (random forest) and deep learning (ultralytics yolo) to detect lesions and grade the severity.
